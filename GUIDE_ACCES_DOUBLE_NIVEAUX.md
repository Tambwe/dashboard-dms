# Guide d'Accès aux Deux Niveaux d'Enregistrement

## Vue d'ensemble

Le système de gestion des ménages dispose maintenant de **deux entrées séparées** dans le menu principal, permettant d'accéder directement à chaque niveau d'enregistrement selon vos besoins.

---

## 🏠 Ménages - Niveau 1 (Chef + Totaux)

### Description
Point d'entrée pour l'enregistrement initial des ménages avec les informations du chef de ménage et les totaux agrégés par catégorie.

### Icône du Menu
- 🏠 Maison avec icône bleue
- Sous-titre : "Chef + Totaux"

### Fonctionnalités
- ✅ Créer un nouveau ménage (Niveau 1)
- ✅ Voir la liste de tous les ménages (Niveau 1 et 2)
- ✅ Modifier les informations du chef de ménage
- ✅ Enregistrer photo et empreinte du chef
- ✅ Saisir les totaux par catégorie :
  - Nombre d'hommes (18+)
  - Nombre de femmes (18+)
  - Nombre de garçons (0-17)
  - Nombre de filles (0-17)
  - Total personnes calculé automatiquement
- ✅ Passer un ménage au Niveau 2

### Quand utiliser ?
- Premier enregistrement d'un ménage
- Enregistrement rapide avec totaux agrégés
- Mise à jour des informations du chef
- Vue d'ensemble de tous les ménages

### Workflow Niveau 1
```
1. Cliquer sur "Ménages - Niveau 1" dans le menu
2. Cliquer sur "Nouveau Ménage"
3. Remplir le formulaire Niveau 1
4. Capturer photo et empreinte du chef
5. Saisir les totaux agrégés
6. Enregistrer
7. Option : Passer au Niveau 2 pour l'enregistrement détaillé
```

---

## 👥 Membres - Niveau 2 (Détails complets)

### Description
Point d'entrée pour la gestion détaillée des membres individuels des ménages. Permet d'enregistrer chaque personne avec toutes ses informations personnelles et biométriques.

### Icône du Menu
- 👥 Groupe de personnes avec icône violette
- Sous-titre : "Détails complets"

### Fonctionnalités
- ✅ Vue d'ensemble des ménages Niveau 2
- ✅ Statistiques globales :
  - Total ménages Niveau 2
  - Total membres enregistrés
  - Moyenne membres par ménage
  - Données biométriques complètes
- ✅ Progression de complétude par ménage
- ✅ Accès direct pour ajouter des membres
- ✅ Gestion individuelle de chaque membre
- ✅ Filtrage par site, statut, recherche

### Informations Collectées par Membre
- **Identité complète** : Nom, postnom, prénom, sexe, âge, date/lieu naissance
- **Documents** : Type et numéro de document d'identité
- **Biométrie** : Photo + empreinte digitale
- **Lien familial** : Relation avec le chef de ménage
- **Contact** : Téléphone, email
- **Éducation** : Niveau d'étude, profession, scolarisation actuelle
- **Vulnérabilités** : 7 catégories avec détails spécifiques
- **Observations** : Notes complémentaires

### Quand utiliser ?
- Enregistrement détaillé de tous les membres
- Gestion des ménages déjà au Niveau 2
- Ajout de nouveaux membres
- Modification des informations individuelles
- Consultation des statistiques détaillées

### Workflow Niveau 2
```
1. Cliquer sur "Membres - Niveau 2" dans le menu
2. Vue d'ensemble avec statistiques globales
3. Sélectionner un ménage dans la liste
4. Cliquer sur "Ajouter membre" (icône verte)
5. Remplir le formulaire détaillé Niveau 2
6. Capturer photo et empreinte du membre
7. Enregistrer
8. Répéter pour tous les membres du ménage
```

---

## Navigation entre les Niveaux

### Depuis Niveau 1 vers Niveau 2
```
Ménages - Niveau 1 → Détail d'un ménage → Bouton "Passer au Niveau 2"
→ Confirmation → Ajout des membres
```

### Depuis Niveau 2 vers Niveau 1
```
Membres - Niveau 2 → Bouton "Voir Niveau 1" (en haut à droite)
→ Liste complète de tous les ménages
```

## Codes Couleur

| Niveau | Couleur | Signification |
|--------|---------|---------------|
| **Niveau 1** | 🔵 Bleu | Enregistrement initial, données agrégées |
| **Niveau 2** | 🟣 Violet | Enregistrement détaillé, données individuelles |
| **Complétude** | 🟢 Vert | Ménage complet (tous les membres enregistrés) |
| **En cours** | 🟡 Jaune | Ménage incomplet (membres manquants) |

## Filtres Disponibles

### Filtres Niveau 1
- **Site** : Filtrer par site spécifique
- **Niveau** : Afficher uniquement Niveau 1 ou Niveau 2
- **Statut** : En cours / Complet
- **Recherche** : Nom du chef ou numéro de ménage

### Filtres Niveau 2
- **Site** : Filtrer par site spécifique
- **Statut** : En cours (membres manquants) / Complet
- **Recherche** : Nom du chef ou numéro de ménage

---

## Actions Rapides

### Depuis la Liste Niveau 1
- 👁️ **Voir** : Afficher les détails du ménage
- ✏️ **Modifier** : Éditer les informations Niveau 1
- ⬆️ **Passer au Niveau 2** : Démarrer l'enregistrement détaillé
- 🗑️ **Supprimer** : Effacer le ménage (super_admin uniquement)

### Depuis la Liste Niveau 2
- 👁️ **Voir** : Afficher le ménage avec tous ses membres
- ➕ **Ajouter membre** : Enregistrer un nouveau membre
- ✏️ **Modifier** : Éditer les informations du ménage

---

## Indicateurs de Complétude

### Barre de Progression
La liste Niveau 2 affiche une **barre de progression** pour chaque ménage :

```
█████░░░░░ 50%  → 5 membres enregistrés sur 10 déclarés
```

- **Verte** : Ménage complet (100%)
- **Jaune** : Ménage en cours (< 100%)
- **Pourcentage** : (Membres enregistrés / Total déclaré) × 100

## Cas d'Usage Typiques

### Scénario 1 : Recensement Initial Rapide
```
1. Utiliser "Ménages - Niveau 1"
2. Créer plusieurs ménages rapidement
3. Enregistrer chef + totaux uniquement
4. Plus tard, passer au Niveau 2 si besoin
```

### Scénario 2 : Enregistrement Complet Immédiat
```
1. Créer ménage en Niveau 1
2. Immédiatement passer au Niveau 2
3. Enregistrer tous les membres dans la foulée
4. Ménage complet en une session
```

### Scénario 3 : Gestion Continue des Membres
```
1. Utiliser "Membres - Niveau 2" directement
2. Vue d'ensemble des ménages actifs
3. Ajouter/modifier des membres au besoin
4. Suivre la progression de complétude
```

### Scénario 4 : Analyse et Rapports
```
1. "Ménages - Niveau 1" pour vue globale
2. Statistiques agrégées par site
3. "Membres - Niveau 2" pour détails
4. Données individuelles pour ciblage
```

## Bonnes Pratiques

### ✅ Recommandations

1. **Commencez par le Niveau 1** pour tous les ménages
2. **Passez au Niveau 2** progressivement selon les priorités
3. **Utilisez le menu approprié** selon votre tâche du moment
4. **Complétez les ménages Niveau 2** jusqu'à 100%
5. **Vérifiez régulièrement** les progressions de complétude
6. **Utilisez les filtres** pour cibler votre travail

### ⚠️ Points d'attention

1. Un ménage de **Niveau 2 reste visible** dans les deux vues
2. Les **modifications du chef** se font depuis Niveau 1 ou la vue détail
3. Les **ajouts de membres** ne se font que depuis Niveau 2
4. La **suppression d'un ménage** supprime aussi tous ses membres
5. Les **statistiques Niveau 2** incluent uniquement les ménages passés à ce niveau
