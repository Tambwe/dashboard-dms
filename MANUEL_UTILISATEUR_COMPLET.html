1. Acces et profils

Profil

Super Admin

  • Acces complet a tous les modules.
  • Gere organisations, utilisateurs, references OSSAT.
  • Valide certains workflows (ex: profils services).
Profil

Admin Organisation

  • Gere ses utilisateurs et ses donnees operationnelles.
  • Accede au dashboard organisation et projets associes.
  • Soumet les donnees suivant les regles de role.
Profil

Utilisateur

  • Accede aux sites attribues.
  • Saisit les donnees terrain selon permissions.
  • Peut creer/mettre a jour les enregistrements autorises.

Connexion: page /login

Message "Qualite insuffisante"
Cela signifie qu'une image a ete capturee mais que le moteur de template ne peut pas produire un gabarit fiable, et qu'aucun match JPG exact n'a ete trouve. Refaire une capture avec doigt propre, vitre propre et pression stable.

9. FAQ rapide

Je ne vois pas un module dans le menu

Verifier votre role utilisateur et les permissions associees.

Je ne peux pas modifier un enregistrement

Verifier si l'action est reservee a Super Admin ou au proprietaire de l'organisation.

Import Excel echoue

Utiliser le template fourni dans le module d'import, verifier colonnes, formats et doublons.

Problemes de capture empreintes

Verifier service WebAPI, connexion scanner, qualite de pose et recapturer.

Conseil: conserver ce manuel comme reference centrale, puis ajouter des captures ecran internes par module pour vos sessions de formation terrain.
